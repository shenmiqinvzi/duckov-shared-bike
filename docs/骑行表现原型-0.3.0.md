# 骑行表现原型 0.3.0

日期：2026-10-13。本轮继续改善骑行外观、转向、上下车和车体空间保护。收费、三地图测试站点、车辆欠还与订单欠费限制沿用原设计。

## 已实现的代码

| 内容 | 本轮变化 |
| --- | --- |
| 自行车外观 | 空心轮圈、轮辐、轮毂、曲柄、踏板、前篮和尾部标识；仍由本模组基础几何绘制，未引入游戏资源文件或他人模型。 |
| 轮组与踏板 | 以实际接受的水平位移计算转角，轮胎半径0.4米，踏板与车轮传动比2.4。停车与暂停不空转，后退反转，单次超过3米的位置变化不计为踩踏。 |
| 转向 | 朝输入方向平滑转向，默认540度/秒；单次视觉时间步长最多0.1秒，避免卡顿时突然转身。人物面向与车头同步。 |
| 上车位置 | 1秒过渡结束时重新核对距离、通路、地面和车体空间，把人物移到车辆所在的有效落点，而不是把停放车辆搬到人物脚下。失败保持停车。 |
| 租车与恢复 | 租车前检查完整车体空间，无法生成可用车辆不建立租赁、不收最低费用。恢复的车辆位置已不适合车体时走系统回收，不追加丢失赔偿。 |
| 下车落点 | 按车体朝向在周围1.15米处尝试8个落点，完成过渡时再次检查，避开突然占用的地面。 |
| 车体空间 | 双层水平胶囊包络检测当前位置、移动扫掠及转向中的采样位置。无法转向时尝试保持原朝向，移动被挡时恢复人物到上一接受位置，提示下车或调整方向。 |
| 位置跳转 | 连续骑行中单步超过3米，结束骑行并把车辆保留在原处；租赁继续，不因跳转自动加罚款或迁移车辆。 |
| 原生姿态接入 | 已确认CharacterAnimationControl_MagicBlend使用整型VehicleType参数。骑行时尝试从游戏已加载的摩托载具读取vehicleAnimationType并适配该参数；未找到资源或控制器不支持时沿用原姿态。 |
| 姿态异常处理 | 动画适配异常只停止装饰，不生成回收账单。下车、死亡、场景卸载、读档切槽和停用时解除覆盖；只恢复仍由本模组占用的值。 |
| 脚步声 | 主角骑行时不播放原步行动画触发的脚步声，其他角色保持原逻辑。 |
| 诊断 | F9面板增加姿态适配状态，区分尚未上车、已接入、资源未就绪和异常降级。 |

空间查询使用固定缓冲的NonAlloc物理接口；缓冲满时拒绝该次移动，不把被截断的碰撞结果当作畅通。

## 仍需游戏内验证

**本轮未启动游戏。** 原生坐姿接入只完成了接口核查、代码和编译，不能视为坐姿已验收。

默认NativeRidePoseValue为0，不猜测坐姿编号，也不生成摩托或切换玩家控制对象。实际场景没有预加载对应摩托资源时，会保持原移动姿态并每5秒重新检查。默认人物视觉高度偏移为0；坐姿、手把和车座的贴合需要日后实景校准。

车轮和踏板已有动画，**鸭脚尚未与踏板同步**；本轮没有制作专用骨骼踩踏动画或修改鸭子的骨骼资产。原生姿态适配不是完整的自行车动画系统。

车体空间保护是近似包络和事后位移检查，不是完整刚体车辆物理。坡地、台阶、窄门、NPC接触及陡坡需要日后逐项核实；它可能比步行更保守。原生人物碰撞和重力仍保留。可在配置中关闭VehicleClearance以便对照定位，不能把当前代码检查当作已经证明所有场景都不会穿模。

三地图依旧使用自动寻位测试站点，未确定正式固定坐标。未还车暂不允许切换主地图；下车后当前主地图内的子场景通道维持既有处理。马蜂附加账单区、主动报失默认2000元以及原生异常退出恢复的限制见0.2.0说明。

## 新增配置

`prototype.json`中的Riding段：

```json
"Riding": {
  "NativeRidePose": true,
  "NativeRidePoseValue": 0,
  "RiderVisualHeight": 0,
  "VehicleClearance": true,
  "TurnDegreesPerSecond": 540
}
```

- NativeRidePose开关只控制角色姿态适配。
- NativeRidePoseValue为0时自动查询已加载的原生摩托；正数1～32供后续核实后的适配使用，本版未宣称其中任一编号就是正确坐姿。
- RiderVisualHeight仅在成功接入姿态后调整人物模型高度，允许-0.2～1米，不抬高实际人物碰撞体。
- VehicleClearance控制车体空间保护，默认开启。
- TurnDegreesPerSecond允许90～1080度/秒，控制转向表现，不提高移动速度。

旧版配置缺少Riding段时采用上述默认值，不改变已有地图目标列表及站点位置。安装脚本继续备份原配置后更新本模组包内文件。

## 验证结果

- 125/125项自动验证通过。本轮新增19项，覆盖实际位移与帧数无关的转角、反转、暂停、位置跳变、多圈踏板相位、平滑转向及配置兼容。
- 既有收费、欠费、死亡赔偿、现金回执、三地图路由及500组原生Stat数值对照仍通过。
- 本机目标游戏2.3.30程序集编译0错误、0警告；新增UnityEngine.AnimationModule仅作为本机编译引用，不进入安装包。
- 已通过只读IL核查确认VehicleType参数、ridingVehicleType与原生载具控制之间的关系、Movement.ForceTurnTo仅调整旋转/朝向，以及原脚步声入口。
- 物理查询、原生动画资源发现、姿态贴合、完整上下车过程和真实游戏效果尚未运行验证。离线测试不执行Unity场景或真正的物理查询。
