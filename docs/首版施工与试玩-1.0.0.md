# 共享单车 1.0.0：施工完成与首次试玩

日期：2026-10-14。目标环境：本机Windows Steam《逃离鸭科夫》2.3.30 / build 24013657 / Unity 2022.3.62f2，单人。

首版功能代码、离线测试和安装包已经完成。本文件区分已实现功能与实景验收；本轮没有启动游戏。实际游戏能否正常加载、姿态是否贴合、站点是否适合常用路线、界面是否遮挡，都需要首次试玩确认。

## 先跑通一次租还付款

1. 重启游戏，在模组菜单启用“共享单车”。若已经启用旧版本，也要完全重启才会加载新DLL。
2. 建议先用备用或测试存档。进入零号区，等场景加载完成数秒后打开地图，找绿色站点标记。第一站规划在地堡入口附近，具体落地点以地图标记为准。
3. 靠近站点按F6，阅读租赁须知，再点击租赁。现场不扣现金，也不收押金。
4. 靠近自己的自行车按F7，等待约1秒上车。移动检查车轮、踩踏与转向，再按F7下车。下车只是停车，HUD仍显示未归还和费用。
5. 回到自己的车再次上车，骑往另一站。让自己和自行车都进入站点4米内，F6选择归还；骑行归还会先完成下车。
6. 已还车后正常撤离回地堡。打开马蜂自提点，在右侧“共享单车结算订单”点击一次“提取账单并支付”。不足一小时应扣200元，并出现已付款历史；现金不足时应提示差额、保留订单。
7. 下一次出图能再次租车，说明首轮业务闭环走通。

## 核心规则

每个开始的小时200元，成功租赁最低200元。60分钟整仍是200元，超过60分钟才进入400元；死亡另加2000元，租赁不足一小时死亡的合计为2200元。停车也累计时间，暂停、加载和离线不计费。显示的创建、结束、付款日期仅用于查账，不参与费用计算。

骑行只移除负重带来的减速，不改背包真实重量，也不提高零负重基础速度。伤势、装备、药物等其他速度效果继续生效。骑行及上下车过程中拦截射击、近战、投掷、攻击技能、食药、冲刺、搜刮及丢弃；下车后恢复正常。可以查看地图和背包。

欠车时禁止正常撤离和第二份租赁；停车仍属于欠车。归还后即使没付费，也能正常撤离，但不能再租。马蜂订单是专用结算界面，不占背包格子；点击提取使用原游戏可用现金，银行账户不参与。已付款订单不能重复扣款。

死亡无论发生在骑行还是停车状态，都自动回收并只结算一次。主动报失额外2000元沿用设计默认值。因车辆位置、场景或模组技术异常进行的系统回收只结算已有租赁费，不追加2000元。

普通子场景通道要求先下车，车留在原场景，回来后恢复同一辆车。对于未证实可以双向返回取车的主地图通道，先还车再通行；已确认零号区前往仓库区的原生说明为不可返回，因此属于这种情况。欠费本身不禁止切图。深水或异常位置跳转会停止骑行并将车留在上次位置，租赁继续，可返回取车或报失。

## 骑行与存档的技术落地

自制车体由Unity几何体构成，轮半径0.26米、轴距0.84米，含开放轮辐、车架、把手、座垫、踏板、车篮和反光片。轮转动依据实际接受的移动距离；不动、暂停或停车时不踩空转。车体前后空间检查、转弯速度上限、坡面朝向及安全上下车位置查询独立于移速补偿。

只读游戏资源确认默认 `0_CharacterModel_Duck_Jeff` 的髋、脊柱、上下臂、手、腿和脚骨骼，并确认 `CustomCharacterAnimationController_MagicBlend` 的 `Base Layer.Riding` / `Armature_Riding` 使用 `VehicleType > 0`。本版使用已核实的原生坐姿，随后按自行车握把及踏板位置解算四肢，保持原骨骼长度。上车隐藏当前手持物体的渲染，下车恢复；不通过卸装备改变移速。自定义骨架可能降级为原生坐姿。真实贴合、手脚朝向和其他皮肤兼容仍需实景检查。

租赁、世界位置、付款回执保存于当前原生存档的三个专用键。读档默认停车，保持原租赁累计时间。每5秒及关键节点保存；异常崩溃可能损失最后一个周期内尚未保存的时长与位置，不能用离线时间补算。

付款分准备订单、扣款与回执、订单结清三个持久化阶段，复用同一付款操作ID。本版将现金库存、回执、订单放入同一个原生存档文件提交，并读回核对实际文件数据；提交当前文件时先刷写原生 `.tmp`，再整体替换，保留上一份 `.sharedbike.bak`。替换失败不删除活跃存档。自动测试对三个阶段的替换前后分别中断、丢弃内存再从文件恢复，验证不重复扣款且不会凭空结清。原游戏进程内的真实ES3提交、现金来源和强退场景仍未运行验收。

损坏的车辆布局尝试隔离原数据并无罚款回收；损坏的付款回执停止后续扣款和新租赁，保留欠费供核查。界面显示资料尚未保存时会继续重试，应等待提示消失后正常退出。模组停用会恢复视觉与操作、保留业务记录，重新启用后恢复。

## 第二轮按这些顺序体验

先比较高负重骑行与低负重骑行，检查下车后恢复负重减速；再尝试开枪、背包吃药、冲刺和未归还撤离。若在撤离区域内被拦截，归还后离开该区域再进入，以触发原游戏重新检查。

然后做一次停车死亡，不足一小时应为2200元总账单；在地堡比较现金不足和刚好足额，重复点击已经付款的订单不会再扣款。最后停车后正常返回主菜单、读同一个存档，检查车辆位置和累计费用，再去另外两张地图检查三站。首轮不需要为了跨小时金额而挂一小时，边界已有自动输入验证。

重点反馈坐姿/手脚、车轮转向、窄门坡道、站点距离、地图标记和马蜂面板。与修改移速、输入、动画、撤离或货币的模组同时使用可能有冲突，尚未兼容验收。
