# 1.0.13 改动记录：上下车改用 F 键

日期：2026-11-05
基线：1.0.12（上车判定修复版）

## 1. 需求

上下车原来绑 F7。F7 在键盘上排最右侧，手要从 WASD 区抬起来跨半排键才能按到，骑行中想快速停车/再上车很别扭。

改成 **F**：按一次上车，再按一次下车。其余功能键不动——F5 召车、F6 站点面板、F8 报失、F9 诊断、F10 记录位置。

## 2. 难点：F 是游戏原生的交互键

鸭科夫里 F 是互动键（开门、拾取、搜刮、对话）。直接改绑会带来两个干扰：

1. **没租车时按 F 开门，弹一条"请先租车并靠近你租赁的自行车"**。玩家每次拾取都被打断。
2. **车停在几米外时按 F 与 NPC 对话，弹一条"请先靠近你租赁的自行车"**。

两种都是"模组抢了原生按键的反馈"，比按不到键更烦人。

## 3. 修复

`src/DuckovSharedBike/BikeWorldController.cs` 的 `TryMountOrDismount()` 入口改成静默优先：

```csharp
var actor=Actor!; var rental=_runtime.Engine.CurrentRental;
// F 同时是游戏原生的交互键（开门、拾取、搜刮）。没有自己的车时静默返回，
// 否则玩家每一次正常交互都会收到一条"请先租车"的提示。
if (rental==null || _bike==null) return;
if (_dialogStation!=null) return;
...
var distance=Vector3.Distance(actor.transform.position,_bike.transform.position);
// 车不在身边时同样静默，避免站在门口按 F 开门被"请先靠近"打断。
if (distance>3f) return;
if (distance>2.6f || (distance>1.6f && !SafeGround.Clear(...)))
{ Notify("请先靠近你租赁的自行车。"); return; }
```

也就是：只有"你确实有一辆在租的车、而且人已经站在车旁 3 米内"时，按 F 才会被当成上下车意图；其余情况按键完全交还给游戏，一条提示都不弹。

原生动作的冲突由既有逻辑消化：上车分支本来就有

```csharp
if (actor.CurrentAction!=null && !actor.CurrentAction.StopAction()) { Notify("当前动作尚未结束，请稍后上车。"); return; }
```

按下 F 时如果游戏抢先启动了交互动作，这里会先把它停掉再上车；骑行中按 F 下车时，`LateTick` 的 ride guard 也会清掉被原生交互拽起来的动作。

## 4. 配置

`mod/prototype.json`：

```json
"Keys": {
  "Station": "F6",
  "Mount": "F",
  "Loss": "F8",
  "Diagnostics": "F9",
  "Snapshot": "F10",
  "Summon": "F5"
}
```

`Keys.Mount` 用 Unity Input System 的 `Key` 枚举名，`F`、`F7`、`E`、`Q`、`LeftShift` 都行。解析失败会写日志并回退到 F，不会让模组起不来。键位重复由 `RuntimeSettings.Validate()` 拦下。

## 5. 同步改动的硬编码文案

原来有四处提示把 "F7" 写死在字符串里，改键后会自相矛盾，全部换成运行时 `MountKeyText`：

- `src/DuckovSharedBike/BikeWorldController.cs:538` 租赁成功提示
- `:646` 召车送达提示
- `:731` 距离过远的失败提示（`FailMount`）
- `:753` 车身贴太紧的失败提示

`src/SharedBike.Domain/RuntimeSettings.cs:37` 默认值 `"F7"` → `"F"`；`tests/SharedBike.Domain.Tests/RuntimeSettingsTests.cs:15` 断言同步。

## 6. 验证

- 构建：`scripts\Build.ps1` 0 警告 0 错误。
- 单元测试：`scripts\Test.ps1` 162/162 通过。
- 安装：`scripts\Install.ps1` 覆盖 `Duckov_Data\Mods\DuckovSharedBike`。
- 游戏内需要确认：
  1. 没租车时按 F 开门/拾取，不再出现任何模组提示；
  2. 站在自己车旁按 F 上车，再按 F 下车；
  3. 站在 NPC 或箱子前、车停在 3 米外时按 F，只触发原生交互，不弹"请先靠近"；
  4. 骑行中按 F，能立刻下车，且不会因为交互动作卡住。

## 7. 边界

- F 键无法被模组"消费"，按下时游戏原生交互仍会执行一次。上车路径已经 `StopAction()` 兜底，但如果玩家正对着一台自动售货机按 F，界面可能先弹出来、再提示"请先关闭当前界面再上车"。这是按键共享的固有代价，把 `Keys.Mount` 改回 `F7` 或其他键即可完全避免。
- 3 米静默阈值是经验值：2.6 米是实际上车距离上限，留 0.4 米余量给"人往前走一步"的迟滞，避免在临界点反复提示。
