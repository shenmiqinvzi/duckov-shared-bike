# 1.0.4 速度可见版：为什么“感觉没变快”，以及怎么调到更快

日期：2026-10-21。基线：1.0.3。反馈：骑上单车后感觉速度没有增加，记得要求是“骑上单车后速度按零负重计算”。

## 先回答设计问题

游戏里的负重减速不是一直生效的，而是按重量比例分档：

- 重量 / 最大负重 ≤ 约 0.25：正常，不挂负重减速 Buff；
- > 0.25：轻载档；
- > 0.75：重载档；
- > 1：超重档。

原生 `CharacterMainControl.UpdateWeightState()` 会根据比例调用 `AddBuff(Weight_Light / Weight_Heavy / Weight_SuperHeavy / Weight_Overweight)`。模组做的是：骑行时在 `Stat.get_Value` 里把这些负重 Buff 产生的修正排除掉，等价于“按零负重计算”。

所以：

- 如果你当前没到轻载档（≤25%），**本来就没有负重减速**，零负重速度和当前速度相同，骑行不会变快——这不是补丁没生效。
- 如果你在重载/超重档，骑行应该明显更快；之前只记录了 `Mounted speed=...`，没有“步行速度”对照，所以无法从日志判断属于哪种情况。

## 1.0.4 加了什么

1. **速度对照日志**。上车时同时记录原生速度和骑行速度：
   ```text
   Mounted speed patched=3.969 native=2.811 weight=32.4/40.0 buffs=Weight_Heavy multiplier=1 moveability=0.945 action=none
   ```
   - `native` 是未打补丁的当前负重速度；
   - `patched` 是骑行速度（按零负重 + 可选倍率）；
   - `buffs` 为空且两者相同 → 你不在减速档，设计如此；
   - `buffs` 非空但两者相同 → 负重识别可能失效，把这一行发回即可定位。

2. **上车提示**改为：
   ```text
   骑行中：速度按零负重计算（负重 12.3/40.0），不能战斗或使用食物药品。
   ```
   有额外倍率时会追加 `，速度 x1.15`。

3. **F9 面板**新增“速度：步行 4.20｜骑行 4.20｜负重 12.3/40.0”，随时可看。

4. **可选的额外加速**：
   ```json
   "Riding": {
     "RideSpeedMultiplier": 1.0
   }
   ```
   默认 `1.0`，严格保持“只消除负重减速”。想让单车本身比步行快，改成 `1.15` / `1.25`（允许 0.5–2.0），这是叠加在零负重速度上的乘区。改动后需要重启游戏。

5. **诊断隔离**：`NativeWalkSpeed` 用 `_bypass` 临时关闭补丁读取原生值，避免为了对照而递归或污染缓存。

## 怎么判断

进游戏租车、上车后：

- 看左下角提示或 F9 的“速度”行。
- 若 `native == patched` 且提示里负重比例 ≤25%，说明没到减速档；想更快就把 `RideSpeedMultiplier` 调到 1.15。
- 若 `native > patched`，说明补丁把速度算低了，是 bug；把 `Mounted speed ...` 行发回。
- 若 `native < patched`，补丁生效；差值就是被移除的负重减速。差值小是因为负重档位低。
