# 1.0.15 修复记录：地图站点标记换成八角牌徽章

日期：2026-11-06
基线：1.0.14（骑行中受伤立刻下车）

## 1. 需求

地图上的站点标记太丑，换成参考图那块八角形站牌的样子：深板岩外沿、米白圈、薄荷内线、墨绿底，上下各一条薄荷横杠，左上/右上各一颗橙色铆钉，中间一辆米白自行车。

## 2. 为什么原来丑

三件事叠在一起：

1. **图标来源不对**。`PrototypeAssets` 直接把模组列表卡 `preview.png` 拿去当 POI 图标。那是 256×256 的宣传卡，上面有 "DUCKOV / SHARED BIKE / PLAYTEST" 三行字和一条绿色自行车线稿——缩到地图标记尺寸（十几像素）以后字全糊成一团脏点。
2. **颜色被乘掉了**。`BikeWorldController.AddMarker` 里写着 `marker.Color=new Color(0.2f,0.86f,0.58f)`。`SimplePointOfInterest.Color` 不是"换个颜色"，它是 `UnityEngine.UI.Image.color` 的乘算 tint。`Duckov.MiniMaps.UI.PointOfInterestEntry.Setup` 的 IL 很直白：

   ```text
   ldarg.0 / ldfld icon ; poi.Icon ; callvirt set_sprite
   ldarg.0 / ldfld icon ; poi.Color ; callvirt set_color
   ```

   于是整张徽章被乘上一层荧光绿，米白变豆绿、橙色变土黄，图里的细节全被压平。
3. **尺寸偏小**。`ScaleFactor=0.65` 是为了压住那张糊图，压完只剩一个发绿的小方块。

## 3. 做法

### 3.1 新增独立图标 `mod/marker.png`

参考图是 256×256 透明底，四周留了 12px 空白、最外圈还有 6px 半透明投影。直接当图标用会让主体偏小、边缘发灰。所以先裁边：

```powershell
scripts\Make-Marker.ps1
# 默认 Input  artifacts\art\marker-source.png
# 默认 Output mod\marker.png
```

脚本按 `alpha >= 16` 算内容包围盒，外扩 1px 防锯齿，之后用 `NearestNeighbor` 原尺寸裁剪——不缩放、不插值，色值一个字节都不改。产物是 234×234 的 `mod\marker.png`（7207 字节）。

图标和列表卡从此分开：`preview.png` 继续负责模组菜单里的宣传卡，`marker.png` 只负责地图标记。

### 3.2 加载链：marker.png → preview.png → 程序徽章

`src/DuckovSharedBike/PrototypeAssets.cs` 的构造函数：

```csharp
Icon = LoadIcon(modPath, "marker.png");
if (Icon == null) Icon = LoadIcon(modPath, "preview.png");
_iconFallback = CreateFallbackIcon();
if (Icon == null) Icon = _iconFallback;
_log("Map icon=" + Icon.name);
```

`LoadIcon` 负责把 PNG 读成 `Texture2D`（`ImageConversion.LoadImage`），设 `wrapMode=Clamp`（标记贴图不该平铺）、`filterMode=Bilinear`（缩小的时候别用点采样，不然边缘锯齿乱跳），再 `Sprite.Create` 成居中 pivot 的精灵。失败路径会把半成品纹理 `Destroy` 掉，不留显存垃圾。

三层兜底的意义：玩家把 `marker.png` 删了、或者旧版升级只覆盖了一半文件，地图上也**不会**出现空白标记，最差也是运行时画出来的同款徽章。

### 3.3 颜色置白、尺寸 0.65 → 0.8

`src/DuckovSharedBike/BikeWorldController.cs` 的 `AddMarker`：

```csharp
// POI 的 Color 会乘到图标 Sprite 上，绿色 tint 会把徽章整块染成荧光绿；
// 徽章自带配色，这里必须置白，只靠 ScaleFactor 调大小。
marker.Color=Color.white; marker.ScaleFactor=0.8f;
```

这是整个修复的关键一行。徽章自带配色，任何非白 tint 都是在毁它。`0.65` 提到 `0.8` 是因为现在图里是干净的图形符号（不是文字缩略图），放大也不会糊，反而在路上更好认；再大就会压住地图地名。

### 3.4 程序徽章：和参考图同一套几何

`CreateFallbackIcon()` 从原来那个 32×32 圆圈豆，换成 128×128、每像素 4×4 超采样的八角牌：

| 层 | 内切半径 | 颜色 |
| --- | --- | --- |
| 深板岩外沿 | ≤ 0.985 | `#17282F` |
| 米白圈 | ≤ 0.912 | `#F6F0DD` |
| 薄荷内线 | ≤ 0.806 | `#577F73` |
| 墨绿底 | ≤ 0.752 | `#24343A` |

底色之上画内容：上方薄荷横杠（`#9FC9AE`，圆角矩形）两侧各一颗橙铆钉（`#E2A36E`，半径 0.055），下方一条薄荷横杠，中间米白自行车。

八角形用八法向内切判据，不用线段拼接：

```csharp
var octagon = Mathf.Max(Mathf.Max(Mathf.Abs(x), Mathf.Abs(y)),
                        (Mathf.Abs(x) + Mathf.Abs(y)) * 0.70710678f);
```

自行车是胶囊（点到线段距离 + 圆头）拼的：两个轮圈是"到圆心距离与半径差的绝对值小于笔宽"，车架七根管、车把一根、车座一根，中轴一颗橙点。笔宽 0.05，和参考图的圆头描边比例一致。

超采样是为了边缘：直接按像素中心判定的话，八角牌四条斜边会出明显的阶梯，抗锯齿交给 `Sprite.Create` 的默认设置会糊。4×4 平均后 alpha 也有真正的渐进值。

## 6. 回滚

包在 `artifacts\DuckovSharedBike-1.0.14.zip`，安装前文件在 `artifacts\backups\before-install-20261106-080234-595`。只想回到旧标记的话，把 `AddMarker` 里的 `Color.white` 改回 `new Color(0.2f,0.86f,0.58f)`、`0.8f` 改回 `0.65f` 即可，图标文件留着不影响。

## 7. 可调项

- **大小**：`marker.ScaleFactor`，0.7 保守、0.8 当前、0.9 已经很抢眼。
- **形状感**：想更接近"停车牌"那种压迫感，把外沿半径从 0.985 收一点（比如 0.96），米白圈会显粗。
- **换图**：直接把新的方形 PNG 放到 `mod\marker.png`（建议保留透明边 0 或极少），不用改代码；`Make-Marker.ps1` 只在你需要自动裁边时才用。
