鸭科夫共享单车 1.0.8 · 付费召车版

1.0.8：新增付费召车——不在站点旁时按F5，花100元把最近站点的车调到身边（默认15秒送达，车从站点方向开过来）；新增程序合成音效（扣款成功"叮"、余额不足低鸣、租车/召车/送达提示音），可在 prototype.json 的 Ui.Sounds 关闭。按键、费用与时长均可在 prototype.json 配置（Keys.Summon、Summon.Cost、Summon.Seconds）。
1.0.7：还车、报失、系统回收时立即自动扣款，不再需要回地堡马蜂自提点付款。现金不足或当前无法扣款时订单保持待付款，可在马蜂自提点补付，或下次还车时自动补扣。死亡回收保持原状（复活后补付）。付款幂等保护与旧版一致，不会重复扣钱。
1.0.6：默认加速提升为 x1.5（RideSpeedMultiplier 仍可调 0.5–2.0）。
1.0.5：骑行无视负重并加速——上车即按零负重计算，且默认带基础加速（prototype.json 的 RideSpeedMultiplier 可调 0.5–2.0）。自行车和站点模型重做：车辆带挡泥板、车灯、红色尾灯、警示旗和发光车架条纹；站点换成 2.2 米停机坪+黄色描边+四角灯柱+巨型 P 字灯箱+顶部旋转信标，远距离一眼可见。
1.0.4：上车提示与 F9 面板会显示“原生步行速度 / 骑行速度 / 当前负重比例”，方便确认是否真的在负重减速档。
1.0.3 修复：还车后原生隧道/井盖没有交互点——站点提示让位、欠车拦截提前、返回通道标签、F9 脱困按钮。
1.0.2 改进：启动原生接口自检、周期存档 20 秒、按键与账单面板位置可配置。

适配本机Windows Steam游戏2.3.30（build 24013657），仅单人。

使用方法
1. 重启游戏，在模组菜单启用“共享单车”。
2. 进入零号区、仓库区或农场镇，打开地图寻找绿色单车站点标记。
   各地图三站，按地标在附近安全地面生成。首次进入可能需等待数秒。
3. 靠近站点按F6或用原游戏交互键，点击租赁。不需要现金或押金。
4. 靠近自己的车按F7上车，再按F7下车。下车不是归还，仍然计费。
5. 把自己和车一起带到任意站点4米范围内，F6选择归还——立即自动扣款并提示扣款结果。
   同一账单只扣一次；现金不足或当前无法扣款时账单保留，可在马蜂自提点右侧点击“补付账单”。
   全部付款后才能再租。
6. 不在站点旁时按F5付费召车：先扣100元召车费，自行车从最近站点方向驶来（默认约15秒）。
   扣费后取消不了；落点不安全或租赁失败会自动退款。召来的车按正常规则计费（200元/小时，不足1小时按1小时）。

规则
每个开始的小时200元，最低200元。骑行与停车都计时，暂停、加载和退出不计时。
骑行无视负重减速并额外加速 x1.5；伤势、装备、技能仍影响速度。
骑行不能冲刺、战斗、吃东西、吃药、搜刮或丢弃物品；可以查看地图和背包。
有未归还车辆不能正常撤离或租第二辆；还车后的欠费不阻止撤离。
死亡自动回收，另计2000元赔偿（复活后补付）；报失与系统回收立即自动扣款。
F8打开报失确认；主动报失另收2000元（沿用设计默认值），确认后立即自动扣款。
F5召车需现金≥100元且当前无在租车辆；跨场景召车不会保留，加载时按订单落点恢复。
普通子场景通道先下车，车留在原场景，可返回骑走。
不能保证返回取车的单向跨区通道（例如零号区前往仓库区）必须先还车。
深水或位置跳转会停止骑行，车留在上次位置，租赁继续。

优先试玩
用一个备用/测试存档，先在零号区跑通“租车→上车→停车→异站还车（应立即自动扣款）→再租”。
然后比较高负重与零负重的骑行速度（应该一致且比步行快约 50%），尝试食药、开枪和撤离限制。
接着在离站点较远处按F5：应立即扣100元、听到三连叮，约15秒后车出现在面前并响送达音。
再试现金不足99元时按F5（应低鸣提示且不扣款）、召车途中切场景/进地堡（车按落点恢复）。
最后验证死亡2200元账单、现金不足补付、重复付款，以及停车后正常退出再读档。
坐姿、脚部踩踏、坡地、窄门、地图标记与自动扣款提示仍需你的实际反馈。

排查
F9显示诊断，F10把当前位置记入日志（笔记本可能需要配合Fn）。
日志位于本模组目录 logs/bootstrap.log。
反馈请提供地图、操作、看到的现象及日志末尾；遇到付款异常不要手动删账单。
显示“资料尚未保存”时等待提示消失再正常退出。
默认骨架支持坐姿、握把和踩踏；其他模组替换骨架时可能保留原生坐姿或降级。

停用模组会解除骑行效果并保留业务资料；重新启用后继续恢复。
